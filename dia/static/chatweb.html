O que muda?

  • Tema escuro com camadas de vidro e gradientes sutis.
  • Layout pronto para acoplar a um endpoint de geração.
  • Quick prompts que preenchem o campo automaticamente.

Como conectar ao backend?

  1. Substitua a função mockReply por uma chamada HTTP.
  2. Envie messages como histórico no corpo da requisição.
  3. Atualize statusLabel para refletir o estado da API.

Não há dependências extras além do Tailwind via CDN.

Dica

Use este layout como front-end para o app Gradio existente ou para um endpoint FastAPI customizado. A seção inferior já traz dicas de UX para gravação.
